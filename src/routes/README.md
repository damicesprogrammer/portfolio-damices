# Routes

TanStack Start uses **file-based routing**: every `.tsx` file in this directory
defines a route. `__root.tsx` is the app shell that wraps every page.

## Conventions

| File                     | URL                                              |
| ------------------------ | ------------------------------------------------ |
| `index.tsx`              | `/`                                              |
| `about.tsx`              | `/about`                                         |
| `users/index.tsx`        | `/users`                                         |
| `users/$id.tsx`          | `/users/:id` (dynamic segment)                   |
| `posts/{-$category}.tsx` | `/posts/:category?` (optional segment)           |
| `files/$.tsx`            | `/files/*` (splat, read via the `_splat` param)  |
| `_layout.tsx`            | layout route (renders children via `<Outlet />`) |
| `__root.tsx`             | app shell — wraps every page                     |

`src/routeTree.gen.ts` is generated by the router plugin; don't edit it by hand.
